Demande de suppression des données

Automation Platform respecte le droit des personnes à demander la suppression de leurs données personnelles lorsque cette demande est applicable.

Cette page explique comment demander la suppression des données pouvant être traitées dans le cadre de l'utilisation de Automation Platform, notamment lors d'interactions via WhatsApp.

1. Comment demander la suppression de vos données

Pour demander la suppression de vos données, envoyez un e-mail à :

terhzaz.hicham72@gmail.com

Utilisez de préférence l'objet suivant :

Demande de suppression des données

2. Informations à fournir

Afin de pouvoir identifier les données concernées, veuillez inclure, lorsque cela est applicable :

  1. votre nom et prénom ;
  2. votre numéro de téléphone utilisé lors de vos échanges via WhatsApp ;
  3. votre adresse e-mail si elle a été communiquée ;
  4. le nom de l'entreprise avec laquelle vous avez interagi, si vous le connaissez ;
  5. une description claire de votre demande ;
  6. toute information utile permettant d'identifier les données concernées.
Afin de protéger les données personnelles et d'éviter la suppression d'informations appartenant à une autre personne, Automation Platform peut demander des informations supplémentaires permettant de vérifier raisonnablement l'identité du demandeur.

3. Données pouvant être concernées

Selon les informations effectivement présentes dans la plateforme, une demande de suppression peut notamment concerner :

  • le nom et les coordonnées d'un prospect ou d'un client ;
  • le numéro de téléphone ;
  • l'adresse e-mail ;
  • les conversations enregistrées ;
  • les messages reçus ou envoyés via WhatsApp ;
  • les informations de qualification commerciale ;
  • les préférences ou besoins communiqués lors d'une conversation ;
  • certaines données techniques associées aux messages ou conversations ;
  • les données associées à un prospect, une conversation ou une interaction enregistrée dans la plateforme.

4. Traitement de la demande

Après réception d'une demande valide, Automation Platform examinera la demande et procédera, lorsque cela est applicable, à la suppression ou à l'anonymisation des données concernées.

Le traitement sera effectué dans un délai raisonnable, en tenant compte de la nature de la demande, des systèmes concernés et des obligations applicables.

5. Cas dans lesquels certaines données peuvent être conservées

Certaines informations peuvent être conservées lorsqu'une telle conservation est nécessaire, notamment pour :

  • respecter une obligation légale ;
  • prévenir ou détecter une fraude ;
  • assurer la sécurité de la plateforme ;
  • résoudre un litige ;
  • défendre des droits légitimes ;
  • conserver certaines informations techniques indispensables à l'intégrité du système.

Lorsque cela est possible, les données conservées seront limitées au strict nécessaire.

6. Données liées à WhatsApp

Si vous avez communiqué avec une entreprise utilisant Automation Platform via WhatsApp, certaines données issues de cette conversation peuvent avoir été traitées par la plateforme.

Cela peut notamment inclure :

  • votre numéro WhatsApp ;
  • votre nom de profil lorsqu'il est disponible ;
  • le contenu des messages ;
  • certains identifiants techniques de messages ;
  • certaines informations liées au statut des messages.

Une demande de suppression peut également concerner ces données lorsqu'elles sont effectivement stockées par Automation Platform.

7. Données traitées par des services tiers

Automation Platform peut utiliser certains services tiers nécessaires à son fonctionnement, notamment des services de messagerie, d'hébergement, de base de données, d'infrastructure ou d'intelligence artificielle.

Lorsque des données ont également été traitées par un service tiers, certaines demandes peuvent nécessiter l'application des procédures propres à ce fournisseur.

Cela peut notamment concerner Meta / WhatsApp ou d'autres prestataires techniques utilisés par la plateforme.

8. Délai de traitement

Automation Platform s'efforce de traiter les demandes de suppression dans un délai raisonnable après réception et vérification des informations nécessaires.

Lorsque des informations complémentaires sont nécessaires, le demandeur pourra être contacté à l'adresse e-mail utilisée pour effectuer la demande.
